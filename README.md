# 🌦️SkyCast

A simple Python application that fetches and displays weather-related data using NASA APIs.
This project demonstrates how to retrieve real-time data from an external API and display it in a user-friendly format.

---

## 📌 Features

* Fetch weather or environmental data using NASA API
* Display data in a simple interface
* Python-based implementation
* Easy to run and modify
* Good example for learning API integration

---

## 🛠️ Technologies Used

* Python
* Requests Library
* NASA API
* Virtual Environment (venv)

---

## 📂 Project Structure

nasa_weather_app
│
├── app.py              # Main application file
├── get_data.py         # Handles API requests and data fetching
├── requirement.txt     # Project dependencies
└── README.md           # Project documentation

---

## ⚙️ Installation

1. Clone the repository

git clone https://github.com/Anna948/nasa_weather_app.git

2. Navigate to the project folder

cd nasa_weather_app

3. Create virtual environment (optional)

python -m venv venv

4. Activate virtual environment

Windows:

venv\Scripts\activate

5. Install dependencies

pip install -r requirement.txt

---

## ▶️ Running the Application

Run the main file:

python app.py

The program will fetch and display data from the NASA API.

---

## 🌍 API Used

This project uses the **NASA Open API** to retrieve environmental or space-related data.

Official NASA API Website:
https://api.nasa.gov/
